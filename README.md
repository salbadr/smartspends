# SmartSpends

## Description 

SmartSpends is a personal finance management application that helps users track their expenses, set budgets, and gain insights into their spending habits. It provides an intuitive interface for managing finances, generating reports, and visualizing spending patterns.

## Running the Application
To run the SmartSpends application, use the following command:

```bash
go run ./cmd/smartspends/   
```

## Technologies Used
- Go (Golang) for backend development
